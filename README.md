# Cờ Vua — Royal Clash

Game cờ vua chạy bằng Python và Streamlit.

## Chạy trên máy tính
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Triển khai lên Streamlit Community Cloud
1. Đưa `app.py`, `requirements.txt`, và `README.md` lên GitHub.
2. Vào https://share.streamlit.io/
3. Chọn repository, branch `main`, main file path `app.py`.
4. Bấm Deploy.
